How is edge confidence graded?

Each edge is supported by one or more pieces of evidence — a relation extracted from a single paper by a single model (Opus or Sonnet). At extraction, every piece of evidence is rated high, medium, or low according to how directly that paper supports the relation.

An edge's confidence is the highest level among its supporting evidence: high if any evidence is high; otherwise medium if any is medium; otherwise low. Across the graph: ~6,800 high, ~8,300 medium, 1 low.

Edges where the two models disagreed were settled by a separate arbitration step. Use the Confidence filter above to keep only high (or high+medium) edges; click any edge to read each paper's quoted evidence and its own rating.

Query SaltNet from an AI agent (MCP)

SaltNet ships a local Model Context Protocol server so an AI agent (Claude Desktop, Claude Code, Cline, …) can query the database directly — fully offline, no backend or API key. Three tools:

ToolWhat it returns
search_genesFind genes by free text and/or facets (species, functional category, transport substrate, role).
get_geneOne gene's full record: annotations, supporting PMIDs, per-paper experimental evidence, TCDB annotation, UniProt/NCBI sequence links.
get_gene_networkThe gene's knowledge-graph neighbourhood: connected genes/pathways, edge relations, and the supporting paper evidence (PMID + quoted experiment).

1 · Install

git clone https://github.com/supermanwasd/saltnet.git
cd saltnet/mcp_server
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt

2 · Register with your agent

Use absolute paths, and point the command at the venv Python.

Claude Code:

claude mcp add saltnet -- /ABS/PATH/saltnet/mcp_server/.venv/bin/python /ABS/PATH/saltnet/mcp_server/saltnet_mcp.py

Claude Desktop — add to claude_desktop_config.json:

{
  "mcpServers": {
    "saltnet": {
      "command": "/ABS/PATH/saltnet/mcp_server/.venv/bin/python",
      "args": ["/ABS/PATH/saltnet/mcp_server/saltnet_mcp.py"]
    }
  }
}

Build your own resource

SaltNet was built from the literature by a multi-agent LLM pipeline. That pipeline is packaged as a second MCP toolbox — the build server — so you can construct your own evidence-traceable knowledge graph + database for any topic, with your own keywords and your own choice of models. Eight stages take you from a keyword to a finished resource: search → filter → extract → arbitrate → audit → consolidate → build → check.

Tier A — extraction literature → structured data. LLM-driven, expensive, resumable per PMID (only new papers are processed).
Tier B — build data → database / graph / tables / figures. Deterministic and cheap; re-runs from the master data.

Pipeline flowchart — stage → program → requirement

no LLM runs with just Python/EDirect · LLM · Claude Code costs quota (only 3 stages) · each stage = a make target and an MCP tool
Tier A · literature → structured data (per-PMID, resumable; only 3 stages use the LLM)

2
Filter no LLMPython data stack
make filter  ·  MCP filter_corpus
KeyBERT keywords + SPECTER2 embedding + HDBSCAN clustering → keep on-topic papers. 02_embed.py · 03_cluster.py · 04_keybert.py · 05_filter.py
↓
3
Extract LLM · Claude Code (×2 models)
make extract  ·  MCP extract(model_a, model_b, confirm)
Two independent models extract genes, annotations, and KG triples per paper (abstract + full text). confirm=False returns a cost estimate first. 06_cli_extract_v5.py · 13_extract_fulltext.py · 19_kg_extract.py · loop_*.sh
↓
4
Arbitrate LLM · Claude Code
make arbitrate  ·  MCP arbitrate(confirm)
Adjudicate model disagreements and arbitrate single-model KG edges on full text. 08_adjudicate.py · 14_adjudicate_fulltext.py · 20_arbitrate_disagree.py
↓
5
Audit LLM · Claude Code
make audit  ·  MCP audit()
Per-field Opus re-checks of substrate, functional category, species, and inferred role. 15_audit_transport.py · 16_audit_funccat.py · 17_audit_species.py · 18_audit_role.py
↓
6
Consolidate no LLMPython
make consolidate  ·  (folded into MCP build_kg_db)
Merge per-paper outputs → master gene CSV + KG parquet (consensus + arbitrated). _merge_abstract_fulltext.py · _build_final.py · _kg_strict_plus_arbitrated.py
↓
Tier B · data → outputs (deterministic, cheap, no LLM)
7
Build no LLMPython
make build  ·  MCP build_kg_db('build')
Rebuild the SQLite database, per-species KG JSON, tables, supplementary tables, and figures from the master data. build_db.py · build_kg.py · _make_table*.py · _fig_*.py
↓
8
Check no LLMPython
make check  ·  MCP check()
Recompute the canonical numbers and scan the manuscript for stale ones. check_numbers.py · _qc_transporter_tcdb.py

Install

conda env create -f environment.yml && conda activate saltnet   # Python + EDirect in one go
#   or:  pip install -r requirements.txt        # then install EDirect separately
# Claude Code CLI (only for the LLM stages):  https://claude.com/claude-code

Run it — command line (your keywords)

make search QUERY='("cold stress"[TIAB]) AND plants[MeSH]' MINDATE=2000
make filter
make extract      # LLM · dual-model
make arbitrate    # LLM
make audit        # LLM
make consolidate  # merge → master data
make build        # db + KG + tables + figures
make check

Or drive the same stages conversationally via the MCP server below — heavy LLM stages run as background jobs (get_job / list_jobs) with a cost guardrail.

Register the build server (MCP, stdio)

{
  "mcpServers": {
    "saltnet-pipeline": {
      "command": "/home/<you>/miniconda3/envs/salt_nlp/bin/python",
      "args": [".../pipeline/mcp_pipeline/pipeline_mcp.py"]
    }
  }
}

Point command at the Python from the conda env above and args at your clone's pipeline/mcp_pipeline/pipeline_mcp.py (absolute paths).
